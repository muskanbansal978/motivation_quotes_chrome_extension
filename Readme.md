# 🌟 Motivational Quotes Chrome Extension

A simple Chrome extension that displays a **random motivational quote over a beautiful background image** every time you open a new tab. Stay inspired while you browse! 🚀

---

## 📖 What We Learned

### ✅ **1. Building a Chrome Extension**
- How to create and configure a **`manifest.json`** file.
- How to override the default Chrome **new tab page** using `"chrome_url_overrides"`.
- How to structure an extension with **HTML, CSS, and JavaScript**.

### ✅ **2. Dynamic Content Handling**
- How to **randomly load images** from an array in JavaScript.
- How to **display quotes dynamically** using the DOM (`innerText`).
- How to style and center text **over images using CSS**.

### ✅ **3. Debugging and Enhancements**
- How to **test and load an unpacked extension** in Chrome.
- How to **fix missing images or quotes** by checking the Chrome console.
- How to enhance the extension with **real-time quotes from an API** or local storage.

## 🛠️ How to Use the Extension

### **1️⃣ Install the Extension Locally**
1. **Download or clone this repository.**
2. Open **Google Chrome** and go to:
3. **Enable "Developer mode"** (toggle at the top-right).
4. **Click "Load unpacked"** and select your **extension folder**.
5. The extension is now installed! 🎉

---

### **2️⃣ Open a New Tab**
- Press **`Ctrl + T`** (Windows/Linux) or **`Cmd + T`** (Mac).
- A **random motivational quote** will appear over a **random image**.
- Each time you open a new tab, you'll see **a new image and quote.**

---

### **3️⃣ Troubleshooting**
If something isn't working:
1. Go to `chrome://extensions/` → Click **Reload** on the extension.
2. Open the **Developer Console (`F12` → Console Tab)** to check for errors.
3. Ensure the **image paths are correct** in `script.js`.
